## ✅ 최종 실행 가이드 (2개의 터미널 사용)
이제 딱 2개의 터미널(명령 프롬프트 또는 VS Code 터미널)만 준비하시면 됩니다.

🖥️ 첫 번째 터미널: AI 서버 켜기
이 터미널은 AI 분석을 수행하는 파이썬 서버를 실행하는 데 사용됩니다.

프로젝트 폴더로 이동

DOS

cd C:\Users\SAMSUNG\Desktop\새 폴더\please
필요한 파이썬 라이브러리 설치 (가상환경 없이 바로)

py -m pip를 사용하면 파이썬 설치 시 함께 설치된 pip를 명확히 가리킬 수 있어 오류가 적습니다.

DOS

py -m pip install -r requirements.txt
설치에 몇 분 정도 소요될 수 있습니다.

AI 서버 실행

DOS

python app.py
서버가 성공적으로 켜지면 터미널에 Running on http://... 메시지가 나타납니다. 이 터미널은 끄지 말고 그대로 두세요.

💻 두 번째 터미널: 웹 화면 켜기
이제 새로운 터미널 창을 열고, 사용자가 볼 웹 페이지를 켭니다.

프로젝트 폴더로 이동 (똑같이)

DOS

cd C:\Users\SAMSUNG\Desktop\새 폴더\please
리액트 개발 서버 실행

DOS

npm run dev
이 명령을 실행하면 잠시 후 웹 브라우저에 http://localhost:5173/ 과 같은 주소의 페이지가 자동으로 열립니다.
